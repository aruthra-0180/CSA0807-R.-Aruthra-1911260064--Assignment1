# Village Milk Co-operative Payment Calculator

## Project Description
This project implements a Python-based payment calculator for a village milk co-operative.

## Objectives
- Calculate the rate per litre using fat and SNF values.
- Calculate the farmer's milk payment.
- Validate input values.
- Test payment calculations using Python.

## Technologies Used
- Python
- GitHub

## Project Tasks
This repository contains Task01 to Task12, covering problem analysis, variables, expressions, input validation, functions, modules, testing, calculations, and design improvements.

## How to Run
1. Open the required task folder.
2. Open the Python file in VS Code.
3. Run the program using Python.
